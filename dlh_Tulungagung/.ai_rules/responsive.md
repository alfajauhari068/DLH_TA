# Responsive Layout Operational Rules

- **Container Bounds**: Wrap page sections in container mx-auto px-4 max-w-7xl (1320px limit).
- **Breakpoints**: sm (640px), md (768px), lg (1024px), xl (1280px).
- **Touch Area**: Minimum 44px x 44px touch target size on mobile viewports (<768px).
- **Horizontal Scroll**: Prevent horizontal layout overflow on mobile screens.
