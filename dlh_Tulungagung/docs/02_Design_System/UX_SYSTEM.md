# UX Architecture Specification

**Specification ID:** ESS-DS-007  
**Status:** Approved  

---

## 1. Information Hierarchy & Scanning Patterns
- **F-Pattern Layout:** Applied to dense text pages (News index, PPID listing, Document archives).
- **Z-Pattern Layout:** Applied to landing sections (Hero, CTA, Promotional sections).

## 2. Action Priority
- **Primary Action:** Solid background (g-primary text-white). Maximum 1 per section.
- **Secondary Action:** Outlined border (order border-white/40 text-white or order-primary text-primary).
- **Utility Actions:** Quiet circular icon buttons (w-10 h-10 rounded-full bg-gray-50).
